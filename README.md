# PRII DOCES — Site + Cardápio

O projeto foi separado em duas páginas:

- `index.html` — site inicial/institucional da PRII DOCES.
- `cardapio.html` — cardápio completo com busca, categorias, carrinho, personalização e finalização.
- `landing.css` — estilos exclusivos do site inicial.
- `style.css` — estilos do cardápio.
- `script.js` — funcionalidades do cardápio.

## Como abrir
Abra `index.html` no navegador. O botão **Ver cardápio** leva para `cardapio.html`.

## Configurar WhatsApp e Instagram
No final de `script.js`, altere o objeto `PRII_CONTACTS` com o número e o link do Instagram da loja.
